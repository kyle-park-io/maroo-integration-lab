## 2차 시험: 새 클론에서 연 에이전트 세션 (2026-09-27 13시대 KST)

- 방법: GitHub에서 새로 받은 클론(`229adfc`)을 README가 안내하는 에이전트 도구로 열고, 처음 보는 개발자가 할 질문 여섯 개를 질문마다 새 세션으로 물었다. 허용한 동작은 파일 읽기, 검색, 스킬 불러오기다. 명령 실행, 웹, 파일 수정은 막았고, 스킬을 쓰라는 지시는 하지 않았다. 모델은 도구 기본값이다.
